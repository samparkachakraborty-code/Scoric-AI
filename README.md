# Scoric-AI
Scoric AI is a powerful AI driven automated exam copy checker , It takes the question paper and the answer script and returns the final result with evaluated marks in multiple-different modes e.g. - hard , medium and easy. Currently this project is  in its minor phase . This project will be complete fully by the end of 2026. The main difference is - it doesn't just check the copies , it also evaluates the positive and the negative points of that copy. So it directly impacts on the next steps to make the student more sincere about that subject.
